Trigonometric Ratios (Sin, Cos, Tan)

Memory Trick: How do you quickly remember the formulas for Sin, Cos, and Tan?

SOH · CAH · TOA

SOH: Sin = Opposite / Hypotenuse
CAH: Cos = Adjacent / Hypotenuse
TOA: Tan = Opposite / Adjacent

Line Gradient (Slope) Formula

Memory Trick: Which coordinates go on top in the gradient formula $m = \frac{y_2 - y_1}{x_2 - x_1}$?

Rise over Run (Y before X)

You RISE UP (vertical = $Y$) before you RUN ACROSS (horizontal = $X$).
Formula: $m = \frac{\Delta y}{\Delta x}$
